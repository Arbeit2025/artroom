# お部屋美術館（artroom）

パブリックドメインの有名絵画を、お部屋に飾るように全画面で眺めるための小さな Web 美術館です。収蔵作品は約18点（北斎、ゴッホ、フェルメール、モネなど）。

## 使い方

- **今日の1枚**（トップページ）：JST の日付から決定的に選ばれた1点を表示します。その日は何度開いても同じ作品です。
- **スライドショー**（`/slideshow`）：全作品を全画面で自動切替表示します。切替間隔はクエリで変更できます（例：`/slideshow?interval=10` で10秒、既定30秒、最小5秒）。
- **閲覧履歴**（`/history`）：見た作品と日付・時刻（JST）を SQLite に記録し、一覧で見返せます。同じ日の同じ作品は1回だけ記録されます。

DB のパスは環境変数 `ARTROOM_DB` で変更できます。

## ローカル実行

```bash
pip install -r requirements.txt
python app.py
# http://localhost:5000
```

## テスト

```bash
python -m unittest discover -s tests
```

## Render へのデプロイ

`render.yaml` 同梱。無料プラン（free）の Web Service としてデプロイできます（healthCheckPath: `/healthz`）。

## 制限事項（正直なところ）

- **画像は Wikimedia Commons へのホットリンク（Special:FilePath）で表示しています。画像ファイル自体はこのアプリに含まれません。** Commons 側のファイル名変更や削除で表示できなくなる場合があり、その場合は `app.py` 内のファイル名の修正が必要です。
- 表示はネットワーク越しの画像読み込みに依存します。大きな画像では表示まで時間がかかることがあります。
- 作品情報（タイトル・作者・年）は一般的な美術史の表記に基づく簡易なものです。
- ログイン機能はありません。Render 無料プランでは SQLite の履歴データが再デプロイ等で消える場合があります。
